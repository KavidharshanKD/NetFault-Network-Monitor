Hop-by-Hop Fault Localization Engine
Layer 3 intermediate hop path tracing, gateway isolation, and router latency analysis.
Router Probe Deprioritization Rule

An intermediate traceroute hop timeout does not mean the router has failed. Transit routers frequently deprioritize or drop ICMP TTL-exceeded packets while continuing to forward customer data plane traffic. The target destination is only marked unreachable if subsequent hops also fail.

Persistent Latency Spike Rule

When latency spikes at one intermediate hop and remains elevated across all subsequent downstream hops, NetFault classifies this as a confirmed transit bottleneck rather than host-level degradation.

Shared Subnet & Gateway Correlation

If multiple devices sharing a /24 subnet or default gateway become unreachable concurrently, the failure is localized to the common upstream router or switch, suppressing duplicate individual device failure notifications.
